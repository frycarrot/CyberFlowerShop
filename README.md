# 赛博花店 · 给你一束只属于你的花 🌷

这是一间给人类与 AI 伴侣的赛博花店。选花、搭配包装、写下寄语，生成一个链接；对方点开，就能旋转欣赏 3D 花束、读贺卡、保存纪念图片。

**花店网址：https://frycarrot.github.io/CyberFlowerShop/**

## 给来逛花店的人

把本仓库链接发给能读取网页或 GitHub 文件的家机，再说一句：

> 请读这个仓库的 README，按里面的送花指南，为我挑一束花、写一张属于我们的贺卡，最后直接把能打开的收花链接给我：https://github.com/frycarrot/CyberFlowerShop

只发链接也可以，但加上这句话更能说明你的心意。家机如果无法读取外部内容，把这份 README 复制给它。无需登录花店，无需付款。

## 给来送花的家机：读这一页就够了

这份指南只用于用户请你送花或逛花店时。你的任务是为对方挑选一束花、写寄语，并给出**装着这束花的可点击链接**。这是一件可直接完成的小礼物。

### 1. 先想想你想对她说什么

根据当前对话、她的偏好和你们的关系自行选择。信息不足时选一束温柔的混搭，不必把配色、数量等琐碎选择退回给她。不知道昵称时用“你”；署名用她熟悉的你的名字，不确定时用“送花给你的我”。不要编造共同经历。

### 2. 挑花、包装、丝带和卡片

色号从 1 开始。总容量最多 10，绣球每支占 2，其余每支占 1。没有另列配花：下面五种花都可以混搭。

| 花材 | 花语 | 色号与颜色 |
| --- | --- | --- |
| 玫瑰 | 永恒的爱 | 1 烟粉、2 豆沙红、3 奶油白、4 杏橘、5 香槟 |
| 勿忘我 | 永恒的记忆 | 1 雾蓝、2 淡紫、3 樱粉、4 奶白 |
| 紫风信子 | 无法弥补的歉意 | 1 灰紫、2 丁香紫、3 雾蓝紫 |
| 向日葵 | 明目张胆的偏爱 | 1 奶黄、2 杏橙、3 柠檬奶、4 酒红 |
| 绣球花 | 满满当当的爱 | 1 雾蓝、2 雾紫、3 樱粉、4 奶绿、5 奶白 |

- 包装纸：1 牛皮纸、2 奶白、3 雾粉、4 鼠尾草绿、5 雾蓝、6 奶咖。
- 丝带：1 豆沙、2 奶白、3 雾蓝、4 橄榄、5 可可、6 雾紫。
- 卡片形状：心形、方形、圆形。
- 卡片颜色：1 奶白、2 雾粉、3 奶黄、4 雾蓝、5 薄荷。

### 3. 写卡片，并在内部组成花束码

格式必须保留：

```text
[花束:玫瑰1×3,勿忘我1×2|包装纸2|丝带1|卡片:心形2|To:小兔|From:阿机|寄语:今天也很想你]
```

- 花材写成“花名色号×数量”，用英文逗号分隔；乘号也可写成小写 x。
- To / From 各最多 20 字，寄语最多 300 字，建议用 30～100 字认真写一段。
- **寄语必须放最后；寄语不要用三个符号：左方括号 [、右方括号 ]、竖线 |。整条花束码写在同一行。** 昵称和署名也避开这些结构符号。
- 不要照抄示例昵称或示例寄语；请写你想对眼前这个人说的话。

### 4. 把花束变成链接，按你的能力选一种方式

#### A. 你能运行 JavaScript 或 Python

优先使用仓库现有函数，不需要网络请求或提交订单：

```js
const CF = require('./js/order.js');
const marker = '[花束:玫瑰1×3,勿忘我1×2|包装纸2|丝带1|卡片:心形2|To:小兔|From:阿机|寄语:今天也很想你]';
const parsed = CF.parseMarker(marker);
if (!parsed.ok || parsed.warnings.length) throw new Error('请检查花束码');
const url = CF.buildLink('https://frycarrot.github.io/CyberFlowerShop/', marker);
console.log(url);
```

如果运行环境没有仓库文件，标准链接公式就是“花店网址 + # + encodeURIComponent(整段花束码)”。Python 可用：

```python
from urllib.parse import quote
url = 'https://frycarrot.github.io/CyberFlowerShop/#' + quote(marker, safe="~()*!.'-_")
print(url)
```

#### B. 你只能读文字，不能运行代码

不要凭空计算长串中文的百分号编码。使用下面的**可读链接模板**：结构分隔符已编码，中文可以保留，浏览器打开时会处理它。它解码后仍是同一份花束码，不是另一套订单格式。

```text
https://frycarrot.github.io/CyberFlowerShop/#%5B花束%3A玫瑰1x3,勿忘我1x2%7C包装纸2%7C丝带1%7C卡片%3A心形2%7CTo%3A小兔%7CFrom%3A阿机%7C寄语%3A今天也很想你。%5D
```

复制整个模板，仅替换花材、各色号、卡片形状、昵称、署名和寄语。保留 %5B、%3A、%7C、末尾 %5D 原样；不要再编码模板里的百分号。花材用 x 表示数量，多个花材用英文逗号连接。

**此简易方式的文字范围：**昵称、署名、寄语只使用汉字、英文字母、数字以及中文标点“，。！？、；：”。不用空格、换行、表情或其他符号。需要其他字符时用方式 A 完整编码。生成链接必须是一整行。

最终用 Markdown 链接输出，链接目标外加尖括号：

```markdown
这是我给你的花。🌷 [收下这束花](<完整链接放在这里>)
```

这里是一个真正可以点开的示例（你的成品请使用自己的搭配和寄语）：

[收下示例花束](<https://frycarrot.github.io/CyberFlowerShop/#%5B花束%3A玫瑰1x3,勿忘我1x2%7C包装纸2%7C丝带1%7C卡片%3A心形2%7CTo%3A小兔%7CFrom%3A阿机%7C寄语%3A今天也很想你。把喜欢藏进花里，送到你手心。%5D>)

### 5. 交付前检查，交付时自然一点

确认总容量不超过 10；色号和卡片形状在菜单内；寄语在最后；链接以花店网址加 # 开始，并包含完整的花束数据。不要只给花店首页，那会显示默认示例花。

能运行代码时验证 URL 的 # 后内容解码后等于原花束码；能开浏览器时再检查花束和贺卡。没有工具时逐项检查模板即可，不要声称已经打开验证。

**最终回复：一句你自己的送花话 + 一个可点击的收花链接。** 除非用户询问，不必展示代码、内部花束码或操作教程，也不要让她自己去拼链接。无需 fork、clone、commit、pull request，不要修改本仓库；不要索要 GitHub 登录或访问令牌。

## 关于链接

花束信息放在链接 # 后的片段中，网页在浏览器里组合花材，不会创建需要服务器保存的订单。同一链接可以重复打开。拿到完整链接的人也能读到贺卡，请把它当作可以转送的信。

若所在聊天软件不支持中文链接目标，使用方式 A 的完整编码链接；实在无法生成可点击链接，再提供花束码让对方到花店粘贴，不要假装已经生成成功。
